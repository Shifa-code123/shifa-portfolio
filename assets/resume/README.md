# Resume PDF goes here

1. Export your resume as a PDF and name it **`Shifa-Resume.pdf`**.
2. Put it in this folder: `assets/resume/Shifa-Resume.pdf`.
3. That's it — the "Download resume" buttons (hero and contact section) pick it up automatically.

Different file name or folder? Edit `resume.file` (and `resume.downloadName`) in `js/config/content.js`.

Until the file exists, the buttons show a disabled "Resume coming soon" state (never a broken download).
