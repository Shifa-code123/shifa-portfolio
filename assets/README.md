# Assets

Replace placeholders by dropping your real file at the same path (same name),
or change the path in `js/config/content.js`.

```
assets/images/
  hero-portrait.png            Stage 2  transparent PNG, half-body
  about-portrait.png           Stage 7  transparent PNG, full-body
  project-1/ project-2/ project-3/   cover.png + screenshots
  internship-certificate/      Stage 6  certificate.png (and optional PDF)
  education/                   Stage 5  optional milestone images
  icons/                       small icons / favicon files
  book/                        Stage 3  paper texture, cover details
```

Folders are intentionally empty until their stage; `.gitkeep` files hold them in version control.
